# 镜守 MirrorGuard 🦞

**AI 视觉驱动的长者脑梗极早期预警系统**

---

## 🎯 项目定义

针对北京 450 万老龄人口，利用洗漱间存量场景，打造"无感采集、边缘计算、医疗联动"的脑卒中风险监测闭环。

---

## 🚀 核心功能

### 1. 图片检测模式 ✅

上传单张面部照片，AI 分析脑卒中风险。

**访问：** https://mirrorguard-demo.vercel.app

### 2. 视频实时检测模式 ✅ NEW!

实时视频流检测，混合架构（前端实时 + 云端深度）。

**访问：** https://mirrorguard-demo.vercel.app/index-video.html

---

## 🏗️ 技术架构

### 混合架构设计

```
┌─────────────────────────────────────────────────┐
│              用户设备 (前端)                     │
│  ┌─────────────────────────────────────────┐   │
│  │  MediaPipe Face Mesh (468 点/帧)         │   │
│  │  ↓                                       │   │
│  │  对称性计算 (嘴角/眼睛/鼻唇沟)            │   │
│  │  ↓                                       │   │
│  │  滑动窗口时序分析 (30 帧)                 │   │
│  │  ↓                                       │   │
│  │  异常检测 → 触发警报                      │   │
│  └─────────────────────────────────────────┘   │
│                    ↓                            │
│         (仅上传警报单帧，不传视频流)             │
└─────────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────────┐
│              云端 (Vercel + Anthropic)          │
│  ┌─────────────────────────────────────────┐   │
│  │  Claude Opus 4.6 深度分析                │   │
│  │  ↓                                       │   │
│  │  返回详细报告 + 建议                      │   │
│  └─────────────────────────────────────────┘   │
└─────────────────────────────────────────────────┘
```

### 技术栈

| 组件 | 技术 | 延迟 |
|------|------|------|
| **前端特征提取** | MediaPipe Face Mesh | <10ms |
| **时序分析** | 滑动窗口算法 | <5ms |
| **云端深度分析** | Claude Opus 4.6 | 3-5 秒 |
| **总延迟 (实时)** | 前端处理 | **<50ms** |
| **总延迟 (警报)** | 云端确认 | **3-5 秒** |

## 🛠️ 核心模块

### 1. API 分析 (`api/analyze.js`)
- Claude Opus 4.6 图像分析
- 公平性校准（按年龄/性别分组）
- FAST-CAD 论文启发的 Prompt 工程

### 2. MediaPipe 特征提取 (`api/facemesh-analysis.js`)
- 468 点面部特征分析
- 5 项对称性指标计算
- 风险等级分类

### 3. 视频实时检测 (`utils/video-detector.js`)
- MediaPipe Face Mesh 集成
- 实时对称性计算
- 滑动窗口时序分析
- 警报触发机制

### 4. 时序分析 (`utils/temporal-analysis.js`)
- 滑动窗口分析器
- LSTM 预测器（预留）
- 多模态融合框架

## 🎯 使用指南

### 图片检测

1. 访问 https://mirrorguard-demo.vercel.app
2. 上传面部照片或使用摄像头
3. 点击"开始 AI 风险评估"
4. 查看分析结果

### 视频实时检测

1. 访问 https://mirrorguard-demo.vercel.app/index-video.html
2. 点击"开始检测"
3. 允许摄像头访问
4. 实时查看面部对称性分析
5. 检测到异常时自动上传云端确认

## 🔒 隐私与安全

- ✅ **边缘计算**：视频数据不出设备
- ✅ **最小上传**：仅警报时上传单帧
- ✅ **数据脱敏**：不存储原始视频
- ✅ **合规声明**：健康提醒设备，非医疗器械
